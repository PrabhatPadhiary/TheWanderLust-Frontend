How to install

  1. Tap Download for Android above (best in Chrome).
  2. If Chrome says the file might be harmful, tap Download anyway. Wayraa isn't on the Play Store yet, so Android shows this for every app downloaded from a website.
  3. Open the downloaded file. If asked, allow installing apps from Chrome (you only do this once).
  4. If Google Play Protect shows a warning, tap More details → Install anyway.

Already have Wayraa? Install the new version the same way: it updates in place and you stay signed in.
